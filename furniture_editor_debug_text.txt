Left-click: Draw black tiles, (Solid/blocking furniture collision)
Ctrl + Click: Draw red tiles, (Support tiles, required to overlap with a surface tile)
Shift + Click: Draw blue tiles, (Surface tiles, can place stuff on top of)
P + Click: Draw brown tiles, (Poop-specific placement/logic tiles)
Tab + Click: Draw yellow tiles: (Extra clickable/hitbox areas)
Right-click: Erase a tile
Left/Right Arrow Keys: Cycle through furniture
Shift + Arrow: Jump to next furniture that hasn't been set up yet
Ctrl + Z: Undo any previous changes
Ctrl + S: Save to packed data/furniture_info.data (Deprecated)
Ctrl + F8: Write selected furniture data into an append file
Ctrl + Shift + F8: Overwrite the append file with only the selected furniture data
Ctrl + F9: Dump vanilla furniture names
